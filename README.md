# 🏆 Steam Achievement Tracker

**Steam Achievement Tracker** — это простое настольное приложение на Python для просмотра достижений Steam через **Steam Web API**.

Программа позволяет быстро получать список достижений выбранной игры, разделять их на открытые и закрытые, искать гайды по ачивкам одним двойным кликом и сохранять данные пользователя для последующих запусков.

---

## ✨ Возможности

- 🎮 Просмотр достижений Steam по **Steam ID** и **App ID**
- 🔍 Поиск игры по названию через встроенную базу
- 📚 Локальная база популярных игр (работает без интернета)
- ✅ Разделение достижений на открытые и закрытые
- 🌍 Получение названий достижений через Steam Web API
- 🔎 Поиск гайдов в Google двойным кликом по достижению
- 💾 Автоматическое сохранение профиля
- 🖱 Контекстное меню и поддержка вставки через Ctrl+V

---

## 🛠 Используемые технологии

- Python 3.8+
- Tkinter
- requests
- SQLite
- Steam Web API

# 🔑 Получение Steam API Key

Для работы программы необходим собственный Steam API Key.

1. Авторизуйтесь в Steam.
2. Перейдите на страницу:

https://steamcommunity.com/dev/apikey

3. В поле **Domain Name** можно указать:

```
localhost
```

4. Подтвердите регистрацию.

После этого Steam выдаст ваш персональный API Key.

> ⚠ Не публикуйте его в открытом доступе.

# 👤 Как узнать Steam ID

Программа использует только **Steam ID64**.

Пример:

```text
76561198012345678
```

Получить его можно несколькими способами:

### Через профиль Steam

Если ссылка выглядит так

```
https://steamcommunity.com/profiles/76561198012345678
```

то число в адресе и есть Steam ID64.

### Через steamid.io

Откройте сайт:

https://steamid.io

Вставьте ссылку на профиль.

---

# 🎮 Как узнать App ID игры

### Через страницу игры Steam

Например:

```
https://store.steampowered.com/app/620/Portal_2/
```

Число после `/app/` — это App ID.

### Через SteamDB

https://steamdb.info

Введите название игры.

### Примеры

| Игра | App ID |
|------|---------|
| Counter-Strike 2 | 730 |
| Dota 2 | 570 |
| Team Fortress 2 | 440 |
| Portal 2 | 620 |
| Borderlands 2 | 49520 |

# 🚀 Использование

1. Запустите программу.
2. При необходимости найдите игру через встроенный поиск.
3. Введите Steam API Key.
4. Введите Steam ID64.
5. Проверьте App ID.
6. При желании включите **«Запомнить этот профиль»**.
7. Нажмите **«Получить достижения»**.
8. Просмотрите вкладки **Открытые** и **Закрытые** достижения.
9. Дважды нажмите по достижению, чтобы открыть поиск гайда.

---

# 📂 Сохранение данных

Если включена опция **«Запомнить этот профиль»**, приложение сохраняет:

- Steam API Key
- Steam ID
- App ID

в файл

```text
steam_profiles.json
```

При следующем запуске данные будут загружены автоматически.

Также приложение использует локальную базу игр:

```text
steam_games.db
```

# ⚠ Возможные ошибки

### Ошибка 400

Причины:

- неверный Steam ID;
- неверный App ID.

---

### Ошибка 403

Причины:

- неправильный API Key;
- профиль Steam закрыт;
- API Key зарегистрирован для другого аккаунта.

---

### Превышено время ожидания

Возможные причины:

- отсутствует интернет;
- временно недоступны серверы Steam.

---

### Достижения не найдены

Это может означать, что:

- игра не поддерживает достижения;
- достижения ещё не открывались;
- игра отсутствует в библиотеке;
- профиль закрыт.
