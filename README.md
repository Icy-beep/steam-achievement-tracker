# 🎮 Steam Achievement Tracker

Десктопное приложение на Python (Tkinter) для удобного просмотра достижений Steam. Программа разделяет ачивки на открытые и закрытые, а также позволяет мгновенно искать гайды по ним в Google.

## ✨ Возможности
- 🔍 **Умный поиск игр**: Встроенная база данных (SQLite) с автодополнением.
- 📥 **Быстрый старт**: Кнопка для мгновенной загрузки ТОП-50 популярных игр (работает без интернета).
- 💾 **Автосохранение**: Запоминает ваш API-ключ и Steam ID между запусками.
- 🌐 **Поиск гайдов**: Двойной клик по любой ачивке открывает Google с готовым запросом: `"<Название игры>" ачивка "<Название ачивки>" гайд`.
- 🛡️ **Безопасность**: Файлы с личными данными (`steam_profiles.json`, `steam_games.db`) игнорируются Git'ом и не попадают в репозиторий.

## 🛠️ Установка и запуск

### 1. Требования
Убедитесь, что у вас установлен **Python 3.8 или выше**. Скачать можно с [python.org](https://www.python.org/).

### 2. Клонирование репозитория
Откройте терминал (командную строку) и выполните:
```bash
git clone https://github.com/ВАШ_НИКНЕЙМ/steam-achievement-tracker.git
cd steam-achievement-tracker
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python steam_app.py
```

### ⚙️ Настройка

Для работы программы вам понадобятся два параметра:
1. Steam Web API Key
Перейдите по ссылке: https://steamcommunity.com/dev/apikey
Авторизуйтесь в Steam.
В поле "Domain Name" введите localhost (или любое другое слово).
Нажмите "Register" и скопируйте полученный 32-символьный ключ.
2. Ваш Steam ID (64-битный)
Это число из 17 цифр, начинающееся на 7656....
Как узнать: Зайдите на сайт steamid.io, введите ссылку на свой профиль или никнейм, и скопируйте значение из поля steamID64.
### ⚠️ Внимание: Ссылка на профиль (например, steamcommunity.com/id/ваш_ник) или формат STEAM_0:1:12345 не подойдут.

### 📖 Как пользоваться
Вставьте API Key и Steam ID.
Начните вводить название игры в поле "🎮 Поиск игры" и выберите её из списка (App ID подставится автоматически).
Если игры нет в списке: Нажмите кнопку "📚 База игр" и добавьте её вручную, указав название и App ID (его можно взять из URL страницы игры в магазине Steam).
Нажмите "🔍 Получить достижения".
Двойной клик по любой ачивке в списке откроет браузер с поиском гайда по ней.

### 🐛 Решение частых проблем
Ошибка 400: Вы ввели неверный Steam ID (должно быть ровно 17 цифр) или неверный App ID.
Ошибка 403: Неверный API-ключ, или ваш профиль Steam скрыт настройками приватности (должна быть открыта "Игровая информация").
"Достижения не найдены": Вы никогда не запускали эту игру, или у неё действительно нет системы ачивок.
