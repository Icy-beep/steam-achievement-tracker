# Steam Achievement Tracker

**Steam Achievement Tracker** - это простое настольное приложение на Python для просмотра достижений Steam через **Steam Web API**.

Программа позволяет получать список достижений выбранной игры, автоматически разделяет их на открытые и закрытые, поддерживает поиск игр по названию, поиск гайдов по достижениям и сохранение профиля пользователя.

---

## Возможности

- Просмотр достижений Steam по **Steam ID64** и **App ID**
- Поиск игры по названию через встроенную базу данных
- Автоматическое создание локальной базы популярных игр
- Разделение достижений на открытые и закрытые
- Получение локализованных названий достижений
- Поиск гайдов в Google двойным кликом по достижению
- Автоматическое сохранение последнего профиля
- Поддержка контекстного меню и вставки через **Ctrl + V**

### 3. Установите зависимости и запустите программу

**Рекомендуемый способ - через [uv](https://docs.astral.sh/uv/):**

```bash
uv sync
uv run steam_app.py
```

`uv sync` создаст виртуальное окружение (`.venv`) и установит зависимости точно по `uv.lock`. `uv run` запускает программу прямо внутри этого окружения - активировать venv вручную не нужно.

Если `uv` не установлен:

```bash
pip install uv
```

**Альтернатива - обычный pip:**

```bash
pip install -r requirements.txt
python steam_app.py
```

# Получение Steam API Key

Для работы программы необходим собственный **Steam Web API Key**.

1. Авторизуйтесь в своём аккаунте Steam.
2. Перейдите на страницу:

   https://steamcommunity.com/dev/apikey

3. В поле **Domain Name** можно указать:

```
localhost
```

4. Подтвердите регистрацию.

После этого Steam выдаст ваш персональный API Key.

> ⚠️ Не публикуйте свой API Key и не передавайте его другим пользователям.

# Как узнать Steam ID64

Программа поддерживает только **Steam ID64**.

Пример:

```
76561198012345678
```

Получить его можно несколькими способами.

### Через профиль Steam

Если ссылка выглядит так:

```
https://steamcommunity.com/profiles/76561198012345678
```

то число после `/profiles/` - это ваш Steam ID64.

### Через steamid.io

Откройте:

https://steamid.io

Вставьте ссылку на профиль и получите Steam ID64.

---

# Как узнать App ID игры

### Через страницу игры в Steam

Например:

```
https://store.steampowered.com/app/620/Portal_2/
```

Число после `/app/` является App ID.

### Через SteamDB

https://steamdb.info

Введите название игры в поиск.

# Использование

1. Запустите программу.
2. При необходимости найдите игру через встроенный поиск.
3. Введите **Steam API Key**.
4. Введите **Steam ID64**.
5. Укажите **App ID** игры.
6. При желании включите **«Запомнить профиль»**.
7. Нажмите кнопку **«Получить достижения»**.
8. Просмотрите вкладки:
   - ✅ Unlocked
   - 🔒 Locked
9. Дважды нажмите по достижению, чтобы открыть поиск гайда в браузере.
